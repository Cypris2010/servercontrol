# tools/

Prüf- und Aufnahmeskripte (Pflichtenheft Kap. 11):

- **Fixtures aufnehmen** — echte Server-Antworten (Login, Home online/offline, Mods,
  ModHub-Kategorie, Website-Suche, Beispiel-Logzeilen) als Testdaten sichern.
  Dabei **Zugangsdaten entfernen** (die `configuration`-Felder enthalten Klartext-Passwörter).
- **Formular-Abgleich** — erwartete Feldnamen (Pflichtenheft 6.1) gegen einen echten Server
  vergleichen (Regressionsschutz für die Versionstoleranz).
